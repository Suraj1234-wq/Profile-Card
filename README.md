Profile Card Project:

A simple and responsive Profile Card UI built using HTML & CSS.
This project is perfect for beginners who want to practice frontend development and responsive design.

Features : 
1. Fully Responsive (Mobile, Tablet, Laptop)
2. Clean and Modern UI Design
3. Profile Image with styling
4. Social Media Icons
5. Hover Effects

Technologies Used: 
1. HTML5
2. CSS (Flexbox & Media Queries)
3. Project Structure
